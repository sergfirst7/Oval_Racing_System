# Oval Racing System

Виртуальный пейс-кар для овальных гонок в Assetto Corsa. Это **CSP online script**: сервер отдаёт клиентам ссылку на `oval.lua`, у игроков ничего ставить не нужно. Работает на Emperor ACSM и на любом сервере с Custom Shaders Patch.

Что делает:

- держит **общее для всех состояние** гонки: зелёный флаг / caution / one to go;
- ведёт **виртуальный пейс-кар**: одна и та же точка на трассе у всех игроков (считается по синхронному времени сессии);
- показывает каждому игроку **HUD**: флаг, за кем ехать, дистанцию, скорость и лимит, предупреждения; на трассе рисует маркер пейс-кара;
- следит за правилами для своей машины: лимит скорости, обгон, отставание.

## Подключение

В панели ACSM: **Custom Shaders Patch → Extra Options**:

```ini
[SCRIPT_0]
SCRIPT = 'https://raw.githubusercontent.com/sergfirst7/Oval_Racing_System/<commit-или-тег>/oval.lua'
REQUIRED = 0
REFRESH_PERIOD = 0
```

- Ключ называется `SCRIPT` ([документация CSP](https://cup.acstuff.club/docs/csp/misc/server-extra-options)). Строки `SCRIPT_TYPE` и `CODE_URL`, которые стояли раньше, в документации CSP не описаны. Если старая запись у вас работала, при переходе на `oval.lua` всё равно лучше использовать документированную.
- В ссылке лучше указывать **коммит или тег**, а не `main`: тогда слияние PR не меняет скрипт на боевом сервере само. Новая версия включается сменой ссылки. Заодно это решает «кэш»: `raw.githubusercontent.com` кэширует файлы на несколько минут, у нового коммита новый URL.
- При загрузке скрипта первые 20 секунд в левом верхнем углу показана надпись `Oval 9.3 loaded (CSP …)`. Нет надписи — скрипт не загрузился.

Работает только в **гонке** (`Race`). В практике и квалификации молчит.

### Настройки

Любой параметр можно добавить в тот же блок `[SCRIPT_0]`:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `paceKmh` | 100 | скорость пейс-кара |
| `speedTolKmh` | 8 | допуск над лимитом |
| `penalty` | `slow` | чем наказывать за нарушения: `off` (только предупреждения), `slow` (до отсечки газа), `drive` (до проезда по боксам, экспериментально, см. «Штрафы») |
| `graceSec` | 6 | время после выезда пейс-кара, чтобы сбросить скорость: нарушения не считаются |
| `speedSec` | 4 | сколько секунд подряд надо быть быстрее лимита, чтобы это считалось нарушением |
| `passSec` | 1.2 | сколько секунд подряд надо быть впереди машины, за которой едешь, чтобы это считалось нарушением |
| `strikeGapSec` | 8 | одно и то же нарушение считается не чаще, чем раз в столько секунд |
| `slowSec` | 5 | длительность отсечки газа |
| `driveLaps` | 3 | кругов на проезд по боксам (только для `penalty = drive`) |
| `catchupKmh` | 60 | добавка к скорости, пока дистанция до впереди идущего большая |
| `bunchGapM` | 30 | целевая дистанция до впереди идущего, м |
| `paceLeadM` | 300 | на сколько метров впереди лидера появляется пейс-кар |
| `autoCaution` | 1 | 1: авария или остановившаяся машина сама вызывает caution |
| `slowKmh` | 40 | ниже этой скорости машина считается остановившейся |
| `limpRatio` | 0.5 | машина медленнее этой доли своей же скорости (и медленнее 110 км/ч) тоже считается остановившейся; 0 отключает |
| `wreckDropKmh` | 60 | потеря такой скорости за 0,4 с считается аварией (после удара порог ниже: 35 км/ч за секунду) |
| `stopSec` | 3 | сколько секунд машина должна быть такой медленной (вне боксов), чтобы это считалось инцидентом |
| `raceKmh` | 80 | машина учитывается, только если после последнего зелёного набирала эту скорость (стоящая на решётке — не инцидент) |

| `cooldownSec` | 4 | сколько секунд после зелёного флага автоматический caution не срабатывает |
| `rolling` | 1 | 1: гонка стартует за пейс-каром (rolling start), 0: обычный стоячий старт |
| `formationLaps` | 1 | пейс-круги rolling start до зелёного флага (считая круг, в котором пейс-кар уходит) |
| `startLeadM` | 40 | на сколько метров впереди поула стартует пейс-кар |
| `cautionLaps` | 1 | минимум кругов пейс-кара при caution до зелёного (считая круг, в котором пейс-кар уходит) |
| `maxCautionLaps` | 4 | после стольких кругов зелёный даётся в любом случае |
| `oneToGoAt` | 0.75 | пейс-кар уходит только в последней четверти круга (положение на трассе 0..1), зелёный даёт линия старта/финиша |
| `paceModel` | `content/cars/aston_vantage2018/aston_vantage2018.kn5` | 3D-модель пейс-кара (путь от папки игры), пустое значение: только стрелка |
| `paceFlip` | 0 | 1: развернуть модель, если она поедет задом наперёд |
| `paceLightA`, `paceLightB` | `g_safety_red`, `g_safety_yellow` | меши светящихся линз в модели, которые мигают по очереди |
| `everySession` | 0 | 1: работать в любой сессии (для тестов) |
| `debug` | 0 | 1: отладочная панель (в чате `!ovaldebug` включает и выключает её только у вас) |

### Команды админа

Пишутся в чат (после `/admin пароль`). В CSP с 0.3.0-preview110 команда в общий чат не попадает. В более старом CSP перехватить набранное нельзя: сообщение остаётся в чате, но команда всё равно срабатывает, когда оно возвращается от сервера.

- `!yellow` — выпустить пейс-кар;
- `!green` — снять caution.

## Rolling start

Сервер по-прежнему запускает гонку стартовым светофором со стоячего старта, заменить это скриптом нельзя. Скрипт ждёт **зелёного огня игры**: пейс-кар выходит в момент, когда закончился отсчёт (`sim.timeToSessionStart`), а если игра его не отдаёт, то когда поле, стоявшее на решётке, тронулось. Часы сессии для этого не годятся: они идут с нуля с момента создания сессии, за 30 секунд до огней.

После огней пейс-кар стартует на `startLeadM` метров впереди поула, поле идёт за ним в стартовом порядке один пейс-круг (`formationLaps`). В последней четверти круга пейс-кар уходит (one to go), лидер держит темп, и зелёный флаг даётся, когда он пересекает линию старта/финиша. Итого один круг и старт. В первые 15 секунд правила мягче: машины разгоняются с решётки в два ряда, поэтому обгоном считается опережение соседа по ряду больше чем на 12 м.

Порядок берётся с решётки (`racePosition`). Пейс-круг идёт в зачёт гонки как обычный: для гонки на круги его нужно добавить к дистанции. `rolling = 0` возвращает стоячий старт. В лог CSP пишутся сигналы старта (`Oval: waiting for the lights ...`, `Oval: lights out ...`) и решётка.

Двойной ряд на пейс-круге не принуждается: скрипт следит за порядком, скоростью и обгоном, но не за тем, в каком ряду едет машина.

## Пейс-кар на трассе

Пейс-кар рисуется моделью машины из папки игры (по умолчанию Aston Martin Vantage 2018, `paceModel`): у каждого игрока в одной и той же точке трассы, повёрнут по ходу движения. Высота берётся не из сплайна (на вираже с креном он расходится с асфальтом), а лучом по физике трассы: машина стоит на дороге и наклонена вместе с ней. Если луч недоступен, остаётся высота сплайна (в лог пишется `Oval: no ground ray`).

У модели есть своя штатная мигалка safety car на крыше (`g_safety_red`, `g_safety_yellow`). Мигают её собственные линзы: скрипт по очереди зажигает их свечение (`ksEmissive`) двойной вспышкой, а два источника света подсвечивают окружение в цвет линзы. Отдельных «квадратов» на экране нет. Для другой модели имена мешей задаются в `paceLightA` и `paceLightB`. Модель загружается при первом выезде пейс-кара, без задержки кадров. Она нужна у каждого игрока: машина из `paceModel` должна быть в списке машин сервера или установленной у всех.

Столкнуться с пейс-каром нельзя: это только картинка, без физики. У каждого клиента физика своя, поэтому физическая машина существовала бы для каждого отдельно, а расхождение часов даёт несколько метров. Обгон пейс-кара наказывается правилами скрипта, а не аварией.

Если модель не загрузилась (нет файла), остаётся стрелка с надписью, причина пишется в лог CSP (`Oval: pace car model failed: ...`). Если машина едет задом наперёд, поставьте `paceFlip = 1`.

## Как проходит caution

1. **Caution.** Пейс-кар появляется на `paceLeadM` метров впереди лидера. Порядок машин фиксируется по положению на трассе. Каждый должен ехать за впереди идущим (лидер за пейс-каром), не обгонять и не превышать лимит: `paceKmh`, а пока дистанция до впереди идущего большая, больше на `catchupKmh`. Чем ближе к нему, тем ниже лимит.
2. **Сбор пелотона.** Пока хоть одна машина стоит на трассе, рестарта нет. Рестарт возможен, когда набралось `cautionLaps` кругов, а каждая машина ближе чем на две дистанции `bunchGapM` к впереди идущему (лидер: на три). После `maxCautionLaps` кругов рестарт даётся принудительно.
3. **One to go.** Когда пелотон собран и пейс-кар проехал `cautionLaps` кругов (круг, в котором он уходит, входит в счёт), он убирается в последней четверти круга (`oneToGoAt`). Лидер держит темп `paceKmh` до линии.
4. **Зелёный.** Зелёный флаг даётся, когда лидер пересекает линию старта/финиша. Если пересечь её некому (все уехали в боксы), флаг зеленеет сам через 1,5 круга.
5. Машина, уехавшая в боксы, выпадает из порядка. Вернувшись на трассу, она занимает место там, где встала в колонну, поэтому боксами обогнать поле нельзя.

**Что вызывает автоматический caution.** Каждый клиент следит только за своей машиной: у неё самой точные данные, и это не зависит от того, чей клиент «главный».

- **Авария:** резкая потеря скорости: `wreckDropKmh` (60 км/ч) за 0,4 с, или 35 км/ч за секунду после сообщения игры об ударе, или падение меньше чем до 35 % скорости перед ударом. Не нужно, чтобы машина остановилась: удар в стену на 250 км/ч, после которого машина катится на 140, тоже авария. Царапина и жёсткое торможение аварией не считаются.
- **Остановка:** машина вне боксов медленнее `slowKmh` дольше `stopSec` секунд, или волочится медленнее `limpRatio` от своей скорости (при этом медленнее 110 км/ч).
- Ни то ни другое не срабатывает, пока машина не набирала `raceKmh` после последнего зелёного (стоящая на решётке не считается), и в первые `cooldownSec` секунд после зелёного.
- В лог CSP пишутся `Oval: contact ...`, `Oval: wreck ...`, `Oval: stopped car ...` с цифрами: по ним можно подобрать пороги.

`autoCaution = 0` отключает автоматику, `!yellow` работает всегда.

## Штрафы

Нарушения при пейс-каре, формации и one to go судит клиент игрока **для его собственной машины**.

| Что считается нарушением | Вес |
|---|---|
| быть быстрее лимита дольше `speedSec` (при рестарте: быть быстрее темпа до зелёного флага) | 1 |
| быть впереди машины, за которой едешь, дольше `passSec` | 1 |
| обогнать пейс-кар | 2 |
| обогнать до зелёного флага (прыжок на рестарте) | 2 |

Не считается: первые `graceSec` секунд после выезда пейс-кара (нужно успеть сбросить скорость) и 15 секунд формации; боксы; 3 секунды после контакта (могли толкнуть); одно и то же нарушение чаще раза в `strikeGapSec`.

Счёт идёт по выезду пейс-кара и обнуляется при следующем:

1. сумма 1: **предупреждение** на экране (красная плашка, сообщение игры);
2. сумма 2: **отсечка газа** на `slowSec` секунд (`SlowDown`);
3. сумма 3 и больше: ещё одна отсечка газа (пока предыдущая идёт, новая не назначается: `GAS CUT (ALREADY ACTIVE)`).

Обгон пейс-кара или прыжок на рестарте (вес 2) даёт отсечку газа уже с первого раза. `penalty = off` оставляет одни предупреждения. Все штрафы пишутся в лог CSP (`Oval: GAS CUT 5 S - ...`); если игра штраф не приняла, на плашке появляется `(NOT ENFORCED)`.
**Проезд по боксам (`penalty = drive`) экспериментальный и по умолчанию выключен.** В двух тестах игра показывала чёрный флаг и телепортировала машину в боксы (после чего ехать было нельзя) на первом же пересечении линии после выдачи `MandatoryPits`: и когда штраф выдавали на caution (`driveLaps = 2`), и когда его выдали через 2 секунды после зелёного флага (`driveLaps = 3`, 3 машины в поле). Круги на исполнение игра при этом, судя по всему, считает не так, как написано в документации. Что скрипт делает в режиме `drive`: нарушение под caution записывается в долг (красная полоса `DRIVE-THROUGH DUE AFTER THE GREEN FLAG`), после зелёного флага выдаётся штраф, он считается отбытым, когда машина проехала через боксы; если игра всё же показала чёрный флаг, скрипт снимает его (`ReleaseBlackFlag`), чтобы игрок не остался в боксах навсегда. В лог CSP пишется, что игра делает со штрафом: строки `Oval: game penalty <тип>/<кругов осталось> lap <круг> pit <в боксах>`. По ним можно понять, как игра считает круги (при загрузке скрипта в лог пишется ещё `Oval: session laps=… timed=…`: в гонке на время у игры нет числа кругов, возможно, из-за этого ей нечего считать). Для проверки включите `penalty = drive` и большой `driveLaps` (например 12).

Ограничения: это клиентская проверка, честная игра держится на том, что игрок не отключает скрипт (см. «Ограничения»). `SlowDown` работает не при любых настройках гонки: в правилах сервера не должна быть включена опция «Disable gas cut penalty». Сообщения о штрафах видит только сам оштрафованный игрок.

## Как это устроено

- **Один файл.** Один и тот же код исполняется у всех игроков.
- **Общее состояние** рассылается через `ac.OnlineEvent`: фаза, время старта, стартовая точка пейс-кара, порядок машин. Сообщение отправляют только при смене состояния. Версия сообщения растёт (`seq`); при одновременных командах побеждает отправитель с меньшим session ID.
- **Пейс-кар** не передаётся по сети: его позиция = стартовая точка + скорость × (`sim.currentSessionTime` − время старта). Время сессии синхронно у всех клиентов, поэтому маркер у всех в одном месте.
- **Порядок машин** фиксируется в момент выезда пейс-кара по физическому расположению на трассе (кто ближе позади пейс-кара, тот первый). Машины, отставшие на круг, не создают ложных «обгонов».
- **Правила** проверяет клиент для своей машины. Расстояние до впереди идущего накапливается кадр за кадром: на кольце «впереди на 0,95 круга» и «позади на 0,05 круга» выглядят одинаково, и по одной позиции обгон не определить.
- Ведение рестарта (порядок, one to go, зелёный) считает каждый клиент, но действует первым тот, у кого минимальный session ID. Остальные ждут `0,4 с × место в очереди`, и если за это время пришло новое состояние, ничего не делают. Поэтому машина без скрипта (или с устаревшим CSP) с низким ID рестарт не блокирует.
- Если у отправителя состояния пропал клиент, следующий по очереди объявляет состояние заново, чтобы его получили и подключившиеся позже.
- Каждая смена состояния пишется в лог CSP (`Documents/Assetto Corsa/logs/custom_shaders_patch.log`, строки `Oval: state ...`): по ним видно, кто и почему вызвал caution.

### Ограничения

- Клиентский скрипт можно изменить или отключить. Жёсткий контроль нарушений остаётся за серверными средствами (ACSM Custom Penalties, KissMyRank и т. п.).
- Команды `!yellow` / `!green` принимаются от любого клиента, который их шлёт: проверить права админа у чужого клиента скрипт не может.
- Автоматический caution не отличает аварию от игрока, который встал в гонке на трассе и стоит. Пороги подбираются на реальных гонках.
- Проверено по определениям API CSP build 3879. Более старые сборки: по логу игрока с CSP 0.2.11 (build 3465) версии до 8.6 не загружались совсем, потому что `ac.onOutgoingChatMessage` появилась только в 0.3.0-preview110. С 8.8 функции, которых нет в CSP игрока, отключаются по одной, а остальное работает. Минимальную версию CSP на сервере (сейчас 2153) стоит поднять до проверенной вами.

## Если у игрока ничего не отображается

Скрипт работает на клиентах, поэтому причину видно только в логе самого игрока: `Documents\Assetto Corsa\logs\custom_shaders_patch.log`. Найдите там:

| Что в логе игрока | Что это значит |
|---|---|
| нет строки `Remote server script: ...` | CSP игрока не прочитал настройки сервера: слишком старый CSP или игра запущена без него |
| есть `Remote server script`, но нет `Server Script: SCRIPT_0 ... loaded and ready to run` | скрипт не скачался (`raw.githubusercontent.com` может блокироваться провайдером) или упал при загрузке; ошибка стоит рядом |
| `Oval: ... loaded, CSP N, ... events=false` | в этом CSP нет онлайн-событий: обновить CSP (на экране будет красная надпись) |
| `Oval: chat commands unavailable` и подобные | в этом CSP нет отдельной функции, остальное работает |
| `attempt to call field '...' (a nil value)` в `Failed to process: [string "-- Oval Racing System...` (скрипт не загрузился) | такой функции нет в CSP игрока; в версиях до 8.8 это убивало весь скрипт, начиная с 8.7 регистрации защищены, а ошибки во время работы показываются красной строкой `OVAL error:` в левом верхнем углу |
| загружено, но флаги не приходят | в чате `!ovaldebug`: строка `script on:` показывает клиентов, у которых работает скрипт, `sent/got` считает отправленные и полученные сообщения; в логе строки `Oval: script seen on client N` |

Каждый клиент при входе один раз здоровается сообщением о себе, поэтому по логу видно, у кого скрипт вообще запущен. Чтобы игрок без скрипта не мог зайти на сервер молча, в блок `[SCRIPT_0]` можно добавить `REQUIRED = 1`: тогда при неудачной загрузке игра закроется, и это заметят сразу.

## Тесты

Симуляция нескольких клиентов с поддельным API CSP (шина сообщений с задержкой и лимитом 200 мс):

```bash
luajit tests/sim.lua
```

Подойдёт любой Lua 5.1+. Тест запускается из корня репозитория и идёт около минуты. Проверяет: общее состояние и разрешение конфликтов, позднего игрока, потерю отправителя, предупреждения (честные не получают, нарушитель получает), а также весь цикл автоматического caution: остановившаяся машина, пит-стоп, сбор пелотона, one to go, зелёный на линии, кулдаун и принудительный рестарт.

Проверить в игре: локальный сервер + `SCRIPT = oval.lua` (файл положить в `assettocorsa/extension/lua/online`), в настройках добавить `everySession = 1`.
